# DriveCore Connect 0.1 — local transport experiment

One small Android receiver (test on Android tablet/phone first) and responsive web sender served by the receiver, accessible from Safari/iOS and Chrome/Android. No iOS IPA required. No LocalSora, Shizuku, VPN, certificate injection, OEM package substitution or installation bypass. No Android Auto/CarPlay or vehicle control in this separate prototype. Premium 0.9 remains unchanged.

On a trusted private Wi-Fi network, open receiver, select local IPv4, open shown address in phone browser, enter temporary 128-bit code displayed on receiver, select APK and send. Receiver is foreground-only, five-minute timeout, single successful transfer, 150 MiB maximum, five incorrect attempts close session. Files stored privately until manual export through Android document picker; displays package name and SHA256 but does not establish publisher trust or install. HTTP is not encrypted: do not use untrusted Wi-Fi or send private data. Verify digest against trusted source before installation. No automated installation or update. Vehicle installation of receiver itself not established. A supported installation route must exist before integrating this with Premium. Future encrypted pairing, signed update manifest, telemetry and native mobile clients are not included.
